# CHDS — CH Digital Services platform

Public website (with a live, published-only report feed) + CHDS AI Support (Groq, admin-managed knowledge base) with persistent visitor identity (customer support is AI-only since V7; the dashboard and Telegram keep the case tools for earlier Human Support cases: closure, priority, SLA, history), a private team report portal with My Reports, and a role-based admin dashboard (users, team, reports & publication, revenue, analytics, notifications, security, audit, emergency control, backups, health). Hosted on Vercel, data in Supabase.

**V7 highlights:** platform-wide **animation system** (page transitions, scroll reveal, hover/press/loading states, animated modals, drawers, charts; reduced-motion aware) · redesigned **Admin Login**, **Dashboard**, **Report Portal** and **Public Reports** · customer-facing **Human Support removed** (AI Support only; history and admin tools kept) · approved **password security notice** on the FAQ · comment-free source. See [V7_UPGRADE_NOTES.md](V7_UPGRADE_NOTES.md).

**V6 highlights:** public report **photos** from a separate public bucket (explicit selection, metadata stripped, carousel + lightbox) · **permanent report deletion** (`delete_reports`, verified across database and both buckets, retryable) · redesigned **AI Support** (retry without duplicates, no duplicate messages after refresh) · platform-wide **loading system** · Telegram limited to **seven commands** (`/help /portal /chats /quene /offline /online /cancel`). See [CHANGELOG.md](CHANGELOG.md).

**V5 highlights:** strict, database-enforced *Close This Case* · private report portal (`/report-portal`) + My Reports · public report feed (`/reports`) · Telegram `/report` removed · Team Management Edit/Delete root causes fixed · AI Knowledge Base · Never-Ask-For-Password enforcement · notification center · Operations Analytics. See [docs/V5_GUIDE.md](docs/V5_GUIDE.md) and [docs/CASE_CLOSURE.md](docs/CASE_CLOSURE.md).

## Quick start
1. **Back up** your Supabase database. New installs: run **all of `supabase.sql`** in Supabase → SQL Editor. Existing installs: run only the migrations you have not applied yet — for V5 installs that is **`supabase/migrations/004_v6_publishing_deletion.sql`**, for V4 installs `003` then `004` — *before* deploying the new code ([docs/MIGRATIONS.md](docs/MIGRATIONS.md)).
2. Set the variables from `.env.example` in Vercel (never commit real values).
3. Deploy (Framework: Other, no build command).
4. Open `/api/health`, then `/admin` → sign in (Telegram ID + password + Telegram code) → System Health → *Connect Telegram bot* (also synchronizes the seven-command menu), *Test AI*. Check that bucket `public-report-images` exists ([STORAGE_CONFIGURATION.md](STORAGE_CONFIGURATION.md)).
5. Team members: open the bot and press Start, then /portal for the private report portal link. Grant `delete_reports` only to administrators who must permanently delete reports. Add team profiles in Team Management and staff accounts in User Management.

Full guide: [docs/DEPLOYMENT.md](docs/DEPLOYMENT.md).

## Structure
```
public/            website + dashboard (static). V6: ux.css/ux.js (shared loading system), reports.js (gallery + lightbox). reports.html (public feed), report-portal.html (private, noindex). assets/: site.css/js, reports.js, portal.js, admin.css/js, admin-views*.js (incl. admin-views-v5.js), icons.js, config.js (public settings only)
api/               9 Vercel functions (Hobby limit 12): ai/[a], chat, public/[a], portal/[a], admin/[a], telegram, stats, health, setup
lib/               server code (never served). V6: imagemeta (metadata stripping), publicimages, deletion, tgcommands, admin/v6. Also: core, validate, time, rbac, storage, notify, visitor, ai, knowledge, secrets, reports, reporters, cases, staffnotify, support, handoff, rooms, bot, admin/* (people, support, business, system, v5)
supabase/migrations/ 001_original_schema.sql (unchanged), 002_platform_upgrade.sql, 003_v5_cases_reports_kb.sql, 004_v6_publishing_deletion.sql (all additive)
supabase.sql       001 + 002 + 003 + 004 (generated by `npm run build:sql`)
scripts/           check.mjs (static checks), dev-server.mjs (local Vercel-like server), build-sql.mjs
tests/             unit + integration tests (node:test: unit, api, admin, v5, v6, imagemeta), browser checks at 13 widths (visual/run_v7.py, run_v6.py, run_visual.py), visual + interaction tests (Playwright), test double
docs/              architecture, deployment, security, features, backup & recovery, testing, upgrade notes
TEST_REPORT.md     what was executed, results, and what still needs live credentials
```

## Scripts
`npm run check` · `npm run check:env` · `npm test` · `npm run dev` (real env) · `node scripts/dev-server.mjs --fake` (test double) · with the fake server running: `python3 tests/visual/run_visual.py`, `python3 tests/visual/run_v6.py`, `python3 tests/visual/run_v7.py` · `npm run build:sql`

## Design
Midnight Blue / Electric Blue: background `#080D18`, secondary `#0D1526`, sidebar `#0A1221`, cards `#111D32` / `#17243B`, accent `#3B82F6` / `#60A5FA` / `#2563EB`, text `#F8FAFC` / `#A5B4C7` / `#718096`, borders `#22314A`, success `#22C55E`, warning `#F59E0B`, danger `#EF4444`, info `#38BDF8`. Fonts: Inter (body), Manrope (headings), Geist as fallback. Icons: Lucide geometry, inlined. Reduced-motion supported.
